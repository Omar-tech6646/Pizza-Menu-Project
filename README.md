Pizza Menu Application

A Windows Forms desktop application developed using C# that allows users to customize pizza orders, select toppings, choose sizes, and calculate the total price.

 Overview

The Pizza Menu Application is a graphical desktop application designed to simulate a simple pizza ordering system. It provides users with an interactive interface where they can select pizza sizes, choose crust types, add toppings, and customize their orders according to their preferences.

The application calculates the total order price based on the selected options and displays the order details before confirmation.

The project focuses on developing desktop applications using C# and Windows Forms while practicing event-driven programming and GUI development.

Features

* Pizza Size Selection: Choose from different pizza sizes (Small, Medium, and Large).
* Crust Selection: Select the preferred pizza crust type.
* Toppings Selection: Customize pizzas by adding different toppings.
* Order Customization: Select multiple options to create a personalized pizza.
* Price Calculation: Automatically calculate the total price based on the selected options.
* Order Summary: Display the selected pizza options and total cost.
* Order Management: Confirm or reset the current order.
* Interactive GUI: User-friendly graphical interface with buttons, radio buttons, checkboxes, and other Windows Forms controls.
